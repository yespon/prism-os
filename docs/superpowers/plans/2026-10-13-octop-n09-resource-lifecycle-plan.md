## 下一可交付接缝

先审计原 TenantSkill、personal/shared/public 可见性、管理权限、Agent 已有资源引用、实际文件及 UI 查询身份边界。资源名不能代替具体来源/拥有者/当前权限，列表或旧事实不能作为后续写入/使用授权。保留原姓名冲突、禁用覆盖及 public 默认解析能力。

在原登记与 C1 文件服务上实现明确的复制/分享操作。目标由当前身份和原管理员权限决定；来源必须是当前可读取的具体资源，禁止客户端指定任意绝对路径、其他用户安装位置或用同名 public 回退替代被撤回的来源。先用实际失败重现明确原流程的缺口，再定义变更和验收。

分享/复制不携带 Secret 值、审批结果、历史执行权限或其他用户的 USER/MEMORY 活跃数据；工具绑定等引用在目标范围重新核对。文件与 DB 的中断继续使用已证明的暂存、排他发布和未知保留边界，不建立第二套注册表，不自动绑定 Agent 或获得执行权限。

禁用/撤回先复用原管理与当前 ACL；已绑定/已记录事实可保留历史，但后续使用必须重新授权。删除或回收必须另行证明归属、依赖引用及未知操作边界，不能把禁用等同于递归删除目录或历史事实。
