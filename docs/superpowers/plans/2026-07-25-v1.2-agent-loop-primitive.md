# v1.2 — Agent Loop Primitive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the Agent Loop as an abstraction layer over LangGraph, decoupling platform code from DeerFlow-specific APIs. Build a unified Tool Registry and Message System. This is the first step toward v2.0's autonomous runtime.

**Architecture:** Define `AgentLoop` abstraction that wraps `create_agent` from LangChain (the current DeerFlow loop). `ToolRegistry` replaces `get_available_tools` with a schema-driven registry supporting register/discover/deprecate. `MessageSystem` abstracts conversation history from LangGraph's `AgentState` message model. All three run in parallel with existing DeerFlow code via `OPSINTECH_AGENT_LOOP` feature flag.

**Tech Stack:** Python 3.12+ / LangChain `create_agent` / FastAPI / Pydantic v2 / JSON Schema

## Global Constraints

- **Backward compatibility:** Agent Loop runs in parallel with existing DeerFlow loop via feature flag. Default: legacy DeerFlow. Opt-in: new Agent Loop abstraction.
- **No data migration:** Tool Registry and Message System are additive. Existing tools and messages continue to work.
- **Decoupling, not replacement:** LangGraph is still the underlying runtime. v1.2 is an abstraction layer over it, not a replacement.
- **Tests must pass:** `cd backend && PYTHONPATH=. uv run pytest tests/ -v` green before commit. No regressions.
- **Comparison test metrics:** Tool-call sequence match rate ≥90% (allows order differences), final result success rate no statistically significant difference (human-evaluated sample), Agent Loop latency within ±10% of DeerFlow baseline.

```python
"""AgentLoop — think→act→observe cycle abstraction over LangGraph.

This is a wrapper around DeerFlow's create_agent, not a replacement.
The abstraction isolates platform code from LangGraph-specific APIs
so that v2.0 can swap the underlying runtime without changing platform code.
"""

from dataclasses import dataclass, field
from typing import Any

from langchain.agents import create_agent as langchain_create_agent

from deerflow.agents.lead_agent.prompt import apply_prompt_template
from deerflow.agents.thread_state import ThreadState
from deerflow.config import get_app_config
from deerflow.config.agents_config import load_agent_config
from deerflow.database.user_config_store import load_enabled_tenant_model_names
from deerflow.models.factory import create_chat_model
from deerflow.tools import get_available_tools


@dataclass
class AgentLoopConfig:
    """Configuration for an AgentLoop instance.

    Mirrors the configurable/context params from DeerFlow's make_lead_agent
    but with a clean, typed interface.
    """
    model_name: str | None = None
    thinking_enabled: bool = True
    reasoning_effort: str | None = None
    is_plan_mode: bool = False
    subagent_enabled: bool = False
    max_concurrent_subagents: int = 3
    agent_name: str | None = None
    user_id: str | None = None
    tenant_id: str | None = None
    skill_name: str | None = None


@dataclass
class AgentLoopResult:
    """Result of a single AgentLoop invocation.

    Carries token usage for Q/T/C budget tracking (v1.2 introduces the
    budget concept; v1.4 Plan Schema carries estimated_cost; v1.9 SLO
    definitions cover the T-axis).
    """
    response_text: str
    model_used: str
    token_usage: dict[str, int] = field(default_factory=dict)
    tool_calls: list[str] = field(default_factory=list)
    artifacts: list[str] = field(default_factory=list)


class AgentLoop:
    """Abstraction layer over LangGraph's create_agent.

    This class wraps DeerFlow's make_lead_agent logic into a clean,
    typed interface. The underlying runtime is still LangGraph (via
    create_agent). v2.0 will replace this with an autonomous runtime.

    Usage:
        config = AgentLoopConfig(model_name="gpt-4o", tenant_id="t-123")
        loop = AgentLoop(config)
        result = loop.run(messages)
    """

    def __init__(self, config: AgentLoopConfig):
        self.config = config
        self._agent = None

    def _resolve_model_name(self) -> str:
        config = self.config
        app_config = get_app_config()
        available_names = [m.name for m in app_config.models]

        if not available_names:
            raise ValueError("No models configured")

        tenant_allowed: set[str] | None = None
        if config.tenant_id:
            tenant_allowed = set(load_enabled_tenant_model_names(config.tenant_id))

        # Resolve from agent config if available
        agent_model_name = None
        if config.agent_name and not config.agent_name == "terminal-agent":
            agent_cfg = load_agent_config(config.agent_name, user_id=config.user_id)
            if agent_cfg and agent_cfg.model:
                agent_model_name = agent_cfg.model

        model_name = config.model_name or agent_model_name

        if model_name:
            if tenant_allowed is not None and model_name not in tenant_allowed:
                raise ValueError(f"Model '{model_name}' not available for tenant")
            if model_name not in available_names:
                raise ValueError(f"Model '{model_name}' not found in available models: {available_names}")
            return model_name

        # Fallback: use first tenant-allowed model
        if tenant_allowed:
            for name in available_names:
                if name in tenant_allowed:
                    return name
            raise ValueError("No tenant-allowed models configured")

        return available_names[0]

    def _build_agent(self):
        """Build the underlying LangChain agent (via DeerFlow)."""
        model_name = self._resolve_model_name()
        app_config = get_app_config()
        model_config = app_config.get_model_config(model_name)

        thinking = self.config.thinking_enabled
        if thinking and model_config and not model_config.supports_thinking:
            thinking = False

        model = create_chat_model(
            name=model_name,
            thinking_enabled=thinking,
            reasoning_effort=self.config.reasoning_effort,
        )

        agent_cfg = load_agent_config(self.config.agent_name, user_id=self.config.user_id)
        tool_groups = agent_cfg.tool_groups if agent_cfg else None

        effective_skills = None
        if self.config.skill_name:
            effective_skills = {self.config.skill_name}
        elif agent_cfg and agent_cfg.skills is not None:
            effective_skills = set(agent_cfg.skills)

        tools = get_available_tools(
            model_name=model_name,
            groups=tool_groups,
            subagent_enabled=self.config.subagent_enabled,
        )

        # Build system prompt
        system_prompt = apply_prompt_template(
            subagent_enabled=self.config.subagent_enabled,
            max_concurrent_subagents=self.config.max_concurrent_subagents,
            agent_name=self.config.agent_name,
            available_skills=effective_skills,
            user_id=self.config.user_id,
        )

        return langchain_create_agent(
            model=model,
            tools=tools,
            system_prompt=system_prompt,
            state_schema=ThreadState,
        )

    def run(self, messages: list[dict[str, str]]) -> AgentLoopResult:
        """Execute the Agent Loop on the given messages.

        This is the primary entry point for the abstraction layer.
        It wraps the think→act→observe cycle of the underlying LangGraph agent.

        Args:
            messages: List of {"role": "...", "content": "..."} dicts

        Returns:
            AgentLoopResult with response text, model used, token usage,
            tool calls, and artifacts.
        """
        if self._agent is None:
            self._agent = self._build_agent()

        # Convert messages to LangChain format
        from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

        message_role_map = {
            "user": HumanMessage,
            "assistant": AIMessage,
            "system": SystemMessage,
        }
        langchain_messages = []
        for msg in messages:
            role = msg.get("role", "user")
            msg_cls = message_role_map.get(role, HumanMessage)
            langchain_messages.append(msg_cls(content=msg.get("content", "")))

        # Invoke the LangGraph agent
        result = self._agent.invoke({"messages": langchain_messages})

        # Extract result
        output_messages = result.get("messages", [])
        response_text = ""
        tool_calls = []
        token_usage = {}
        artifacts = []

        for msg in output_messages:
            if hasattr(msg, "content") and isinstance(msg.content, str):
                if not hasattr(msg, "tool_calls") or not msg.tool_calls:
                    response_text += msg.content
            if hasattr(msg, "tool_calls") and msg.tool_calls:
                for tc in msg.tool_calls:
                    tool_calls.append(tc.get("name", "unknown"))
            if hasattr(msg, "response_metadata") and msg.response_metadata:
                usage = msg.response_metadata.get("token_usage", {})
                if usage:
                    token_usage = usage
            if hasattr(msg, "artifact") and msg.artifact:
                artifacts.append(str(msg.artifact))

        return AgentLoopResult(
            response_text=response_text.strip(),
            model_used=self._resolve_model_name(),
            token_usage=token_usage,
            tool_calls=list(set(tool_calls)),
            artifacts=artifacts,
        )
```

```python
"""ToolRegistry — unified tool definition, discovery, and lifecycle.

Tools are platform-managed, not scattered across DeerFlow and custom code.
JSON Schema validation ensures tools are well-defined and discoverable.

See also: executor.py (Executor interface — tools are one type of executor).
"""

from dataclasses import dataclass, field
from typing import Any

from langchain.tools import BaseTool

VALID_SCHEMA_TYPES = {"object", "array", "string", "number", "integer", "boolean", "null"}


@dataclass
class ToolDefinition:
    """Static metadata for a registered tool."""
    name: str
    description: str
    schema: dict[str, Any]
    deprecated: bool = False
    deprecated_at: str | None = None
    deprecated_reason: str | None = None


class ToolRegistry:
    """Unified tool registry with schema validation and lifecycle.

    Usage:
        registry = ToolRegistry()
        registry.register("read_file", tool, schema, description="Read a file")
        tools = registry.discover()  # list all active tools
        tool = registry.get("read_file")  # get by name
        registry.deprecate("old_tool")  # mark as deprecated
    """

    def __init__(self):
        self._tools: dict[str, BaseTool] = {}
        self._definitions: dict[str, ToolDefinition] = {}

    def _validate_schema(self, schema: dict[str, Any]) -> None:
        """Validate that the schema is a valid JSON Schema."""
        if not isinstance(schema, dict):
            raise ValueError("schema must be a dict")
        schema_type = schema.get("type")
        if schema_type not in VALID_SCHEMA_TYPES:
            raise ValueError(
                f"schema type must be one of {VALID_SCHEMA_TYPES}, got '{schema_type}'"
            )

    def register(
        self,
        name: str,
        tool: BaseTool,
        schema: dict[str, Any],
        description: str = "",
    ) -> None:
        """Register a tool with schema validation.

        Args:
            name: Unique tool name.
            tool: The LangChain BaseTool instance.
            schema: JSON Schema dict describing the tool's parameters.
            description: Human-readable description.

        Raises:
            ValueError: If the schema is invalid or the name is already registered.
        """
        self._validate_schema(schema)

        if name in self._tools:
            existing = self._definitions[name]
            if not existing.deprecated:
                raise ValueError(f"Tool '{name}' is already registered")
            # Re-registering a deprecated tool: un-deprecate it
            existing.deprecated = False
            existing.deprecated_at = None
            existing.deprecated_reason = None

        self._tools[name] = tool
        self._definitions[name] = ToolDefinition(
            name=name,
            description=description or tool.description or "",
            schema=schema,
        )

    def get(self, name: str) -> BaseTool | None:
        """Get a tool by name. Returns None if not found."""
        return self._tools.get(name)

    def discover(self) -> list[ToolDefinition]:
        """List all active (non-deprecated) tools."""
        return [
            d for d in self._definitions.values()
            if not d.deprecated
        ]

    def deprecate(self, name: str, reason: str = "") -> None:
        """Mark a tool as deprecated.

        Deprecated tools are excluded from discovery but still retrievable
        via get() for backward compatibility.

        Args:
            name: Tool name to deprecate.
            reason: Why the tool is being deprecated.

        Raises:
            ValueError: If the tool is not registered.
        """
        if name not in self._definitions:
            raise ValueError(f"Tool '{name}' is not registered")
        from datetime import UTC, datetime
        defn = self._definitions[name]
        defn.deprecated = True
        defn.deprecated_at = datetime.now(UTC).isoformat()
        defn.deprecated_reason = reason

    def list_deprecated(self) -> list[ToolDefinition]:
        """List all deprecated tools."""
        return [
            d for d in self._definitions.values()
            if d.deprecated
        ]

    def get_schema(self, name: str) -> dict[str, Any] | None:
        """Get the JSON Schema for a tool."""
        defn = self._definitions.get(name)
        return defn.schema if defn else None

    def __len__(self) -> int:
        return len(self._tools)

    def __contains__(self, name: str) -> bool:
        return name in self._tools
```

```python
"""MessageSystem — conversation history abstraction.

Interface is implementation-agnostic. In v1.2–v1.7 the implementation
adapts to LangGraph's message model. Truly independent at v2.0.

The MessageSystem handles:
  - Conversion between platform-agnostic Message and LangChain message types
  - Conversation state tracking (think→act→observe cycle)
  - Token estimation (used for Q/T/C budget tracking, introduced in v1.2)
"""

from dataclasses import dataclass
from enum import Enum

from langchain_core.messages import (
    AIMessage,
    BaseMessage,
    HumanMessage,
    SystemMessage,
    ToolMessage,
)


class ConversationState(str, Enum):
    """Multi-turn conversation state machine.

    Maps to the think→act→observe→think cycle of the Agent Loop.
    """
    IDLE = "idle"           # Before first user input
    THINKING = "thinking"   # LLM is generating a response
    ACTING = "acting"       # Agent is executing a tool
    OBSERVING = "observing" # Agent is processing tool results


@dataclass
class Message:
    """Platform-agnostic message representation.

    Not tied to LangChain, LangGraph, or any specific framework.
    This is the canonical message format for the platform.
    """
    role: str       # "user", "assistant", "system", "tool"
    content: str
    name: str | None = None
    tool_call_id: str | None = None
    metadata: dict | None = None


class MessageSystem:
    """Conversation history abstraction layer.

    Provides conversion between platform-agnostic Message format
    and LangChain-specific message types. In v2.0, the LangChain
    dependency will be removed and replaced with a native message model.

    Also provides token estimation for Q/T/C budget tracking.
    """

    # Role → LangChain message class mapping
    _ROLE_MAP = {
        "user": HumanMessage,
        "assistant": AIMessage,
        "system": SystemMessage,
        "tool": ToolMessage,
        "ai": AIMessage,
        "human": HumanMessage,
    }

    def to_langchain(self, messages: list[Message]) -> list[BaseMessage]:
        """Convert platform-agnostic messages to LangChain format.

        Args:
            messages: List of platform-agnostic Message objects.

        Returns:
            List of LangChain BaseMessage objects.
        """
        result: list[BaseMessage] = []
        for msg in messages:
            msg_cls = self._ROLE_MAP.get(msg.role, HumanMessage)
            kwargs: dict = {"content": msg.content}
            if msg.name:
                kwargs["name"] = msg.name
            if msg.tool_call_id and msg_cls == ToolMessage:
                kwargs["tool_call_id"] = msg.tool_call_id
            result.append(msg_cls(**kwargs))
        return result

    def from_langchain(self, messages: list[BaseMessage]) -> list[Message]:
        """Convert LangChain messages to platform-agnostic format.

        Args:
            messages: List of LangChain BaseMessage objects.

        Returns:
            List of platform-agnostic Message objects.
        """
        result: list[Message] = []
        for msg in messages:
            role = "unknown"
            if isinstance(msg, HumanMessage):
                role = "user"
            elif isinstance(msg, AIMessage):
                role = "assistant"
            elif isinstance(msg, SystemMessage):
                role = "system"
            elif isinstance(msg, ToolMessage):
                role = "tool"

            result.append(Message(
                role=role,
                content=str(msg.content) if msg.content else "",
                name=getattr(msg, "name", None),
                tool_call_id=getattr(msg, "tool_call_id", None),
            ))
        return result

    def estimate_tokens(self, message: Message) -> int:
        """Estimate token count for a message.

        Uses a simple heuristic: ~4 characters per token for English text.
        This is a rough estimate for Q/T/C budget tracking. A more accurate
        tokenizer (tiktoken or equivalent) can be plugged in at v1.4.5.

        Args:
            message: The message to estimate tokens for.

        Returns:
            Estimated token count (always ≥ 1).
        """
        # Simple heuristic: ~4 chars per token
        # Add overhead for role encoding
        role_overhead = 4
        content_tokens = max(1, len(message.content) // 4)
        return role_overhead + content_tokens

    def estimate_total_tokens(self, messages: list[Message]) -> int:
        """Estimate total token count for a list of messages.

        Args:
            messages: List of messages to estimate.

        Returns:
            Total estimated token count.
        """
        return sum(self.estimate_tokens(m) for m in messages)
```
