## 0. 执行前提（需用户提供的输入）

R0-A（M1 收口）需要以下目标环境，缺失时该任务阻塞但不阻塞 R0 其余五项：

1. 目标数据库（PostgreSQL，已备份）；
2. 测试模型（真实 LLM 凭据，用于诊断 Agent 真实 Tool 调用）；
3. 目标工单 webhook 接收端（可核对幂等键）；
4. 审批人与请求者账号（同租户，另备一名跨租户管理员做隔离反例）。

## 1. R0：收口与迁入试验（1–2 周）

## 3. 实施规则

- 沿用 [M1 实施计划](./2026-09-24-prismos-m1-policy-approval-implementation.md) 的实施规则：先添加能失败的测试；Schema/迁移由平台 Owner 串行提交；功能开关默认关闭；fail closed；每两周可运行演示。
- 门禁仲裁按排期修订 §5.1：四类安全反例不可跳过；非安全债按 20% 回归容量吸收。
- 依赖冲突按排期修订 §5.2 预授权规则处置。
- 上游镜像仅作追溯，不在其中散布 `app.platform` 导入；宿主解耦改动进入独立补丁或提取包。
- 保留一套用户、租户、数据库迁移与业务执行事实源；不出现第二套身份或执行事实。
- 代码布局：迁入能力包候选 `backend/packages/octop-capabilities/`、宿主 Adapter 候选 `backend/app/integrations/octop/`（2026-10-08 建议 §3.1 的候选布局，R0 试验后定稿）。
- 每轮结束按 Q17 裁定滚动细化下一轮计划，落点为本目录独立计划文件。
