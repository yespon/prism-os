## 实际故障与本批修复

修正测试夹具后，原异步调度/原数据库/实际图构建重现 5 项失败：线程等待期间 Agent 配置、Skill 内容、事件标题变化；撤回 Skill 和凭据发行后严重性变化时，旧消息仍可能保留配置副本或事件条件缺少消费核验。首次夹具目录错误和异步任务吞断言的输出另保留，不作实际通过或完整故障证据。

自动诊断的事件消息在线程创建后按原租户/事件重新读取与组装；Agent 角色、Skill 正文和工具范围由受保护具体实例的原 graph 配置/系统提示提供，消息不再保存第二份过期配置。原 helper 的默认 metadata 契约保留供人工/旧入口使用，不以本批推导其全部已修复。

原一次性 capability 的摘要保护 payload 增加明确 `diagnosis_incident_id`。新自动派发始终绑定原事件，发行/消费由宿主查询当前租户事件及当前来源严重性条件；删除、跨租户变化、条件不再满足和 token 改指拒绝。平台核心仍通过宿主回调，不直接依赖告警领域；无新表/注册表/Run 事实，诊断事件标识与原工单 Action 权限保持各自含义。普通代理剔除该服务端字段。
