## 本批实现

管理员在原告警源 `analysis_trigger` 明确确认当前执行 actor 与 shared Agent UUID；服务端丢弃客户端传来的授权字段，无关配置更新保留既有确认，解绑清除确认。缺少原确认的历史源须由当前管理员重新确认，不能从创建者或任意成员推断授权。失效 Agent 不妨碍管理员停用来源。

原自动调度重新检查租户、来源启停/配置摘要、当前管理员成员资格、具体共享实例和当前严重性条件；异步线程创建后再核对。原一次性 capability 表保存完整随机 token 的摘要，受保护 payload 绑定 Agent ID 与来源摘要；核对原 tenant/user/thread/name、过期及当前宿主授权后原子单次消费。平台核心只接受宿主回调，不导入告警领域；无新 schema、注册表或第二套 Run 事实。

共享 UUID 进入原图执行授权、AgentConfig、Skill 快照与 soul 加载，避免同名个人项回退；普通代理剔除客户端服务端选择字段。原 built-in terminal 与 bootstrap 不能冒充原生选择。原行动工具仍需要原 incident/action 权限，不由诊断身份自动授予。
