# 共享自动诊断授权候选：范围与剩余门

本批在原 source 管理 HTTP、自动调度、原 capability 表和宿主图构建间传递真实确认管理员与 shared Agent UUID。实际 Gateway 使用真实 AuthSession/成员表，并通过仅在临时测试应用中定义的 capability probe 核对授权消费；该 probe 不进入生产 router。图配置/soul、异步撤权及调用计数在原数据库和受控 SDK/模型测试中核对，不声称真实外部模型或工单调用。

已覆盖：客户端伪造 actor、配置创建者借用、同名个人/共享选择、当前来源/租户/管理员成员资格、Agent 共享性与启停、来源摘要变化、严重性条件、一次性消费/篡改/重放、普通代理字段过滤、原生选择的 bootstrap/terminal 冒充。旧随机 capability 与原人工诊断相邻回归保留；没有新 schema、执行记录或品牌豁免。

必须继续的边界：

- 历史源缺少确认时由当前管理员显式重新确认。来源编辑器的完整重确认体验、人工诊断与普通按名执行的具体实例选择仍需核对，不能将共享自动路径推导为全部入口完成。
- 自动调度在异步线程创建前组装诊断消息，随后来源/成员/严重性重查及 graph 当前配置重加载不证明消息内旧 Agent 配置与 Skill 内容快照已刷新；此项和图构建前后并发修改、运行中撤权须单独推进。
- 未迁移的旧 Skill 名称/default/terminal 使用授权；主文件快照之外全部成员文件、工具与撤回的使用前授权。
- 真正删除进程中断与恢复，全删除/C2 退出；完整成员摘要的明确复制/分享及目标重授权，不转移 Secret、他人 USER/MEMORY、历史审批或执行许可。
- 固定宿主 b5/b6 升级回退验证当前接入契约，不证明未知未来 Octop 版本的全部行为已自动兼容；后续版本仍经来源差异、适配、原门和真实行为验收。
- N04 真实目标环境/模型/可核对次数接收端与 N07-B 远端 CI 仍缺。M1 未退出，N08 持久执行/委派不启动。

原 N01–N15/O01–O42/F01–F12、33 非 Skill、18 专家/子 Agent、独立 Office、PrismOS 全部规划/能力与退出门保持。外部四个固定包仅来源/制品核对，运行集成和 MCP 版本接缝仍不因此完成。
