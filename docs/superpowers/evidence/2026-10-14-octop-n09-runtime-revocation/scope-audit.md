# 运行中来源/事件撤权、取消与受控 Action 范围

基线6c63e7e，沿用原五个功能里程碑及全部N/O/F；没有新目标或分支。此前文件/图像/结果/历史访问功能块已提交，不重开其验证。

当前Native文件与命令的使用阶段统一验证原当前成员、线程绑定、Agent以及受保护来源修订、授权管理员和事件严重度条件；来源上下文不完整时拒绝。事件被替换线程或已有取消意图后，旧运行不能继续使用资源。实际本地命名空间命令在来源/角色/严重度变化后停止，丢弃未确认输出；已经发生的外部效果不推断为未发生。

自动来源诊断在等待期间定期读取当前授权，返回结果后再次核验，撤权后不发布迟到结果。SDK取消仅在原线程绑定证明拥有者后进行，标识及回复归属校验，只有实际观察到interrupted才报告confirmed；接受请求、空列表、失联、超时或不属于本线程均为unknown。停止本地等待不算远端停止。已记录的用户取消意图不盲重发远端取消。

原事件取消HTTP入口在停止本地任务前核对当前成员及线程归属；先记录停止意图，再请求中断，未确认时返回unknown并保留原IncidentAction中的事实，不能显示为已确认取消。自动等待不得覆盖这个意图。事件原记录携带thread/source/revision/run_ids和external_effects=unknown，不新增Run/Attempt/版本登记表。

原TicketActionAdapter保持Policy/Approval/ActionSubmission/Audit/幂等和unknown流程，增加可注入实时执行授权门，默认Native受控工具启用；准入、提交前与发送前核验当前授权，已生成allow不能越过随后撤权。原契约隔离适配器仍可显式注入自己的授权边界，不能把其模拟发送算真实工单调用。
