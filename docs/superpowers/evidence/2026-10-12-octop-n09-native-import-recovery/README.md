# N09-C1 后端：原生导入发布与恢复证据

基线 `97d5ab0`，分支 `codex/octop-integration`。本批完成后端接缝及固定来源安装 API，完整 C1 界面与完整 N09 未退出。N01–N15、O01–O42/F01–F12 和原 PrismOS 规划/门禁保持。

原三条真实失败先红后绿：复制故障不再留下最终半成品；同名并发返回原冲突类型；DB 已提交后的响应失败保留已注册文件。现在同文件系统暂存、复制前后摘要及严格格式核对、排他发布后，再复用原 TenantSkill 登记。发布后异常不删除最终目录；本操作自有暂存有目录 identity 核对，替换目录不能误删。

当前 tenant/actor 范围可查询记录、明确恢复或放弃自有暂存。完整暂存可在再次排他发布后登记；发布后进程退出可从原收据和实际 dev/inode/摘要核对。已存在且路径/内容相符的原生行只观察，不重复创建、不启用禁用项；冲突、改变、无法核对保留现状。文件系统与 DB 不是单事务，收据不成为第二个注册表或平台执行事实。

固定公开来源安装只接受个人/租户 scope 与确认过的 bundle SHA。服务端校验全部来源、三处有限格式映射与版权附件，使用相同服务；路径/其他用户参数拒绝，租户共享使用原管理员权限。安装仍不绑定 Agent 或授予依赖/Secret/执行权限。
