# 文件、图像、线程结果与历史访问范围审查

继续 codex/octop-integration，基线 4694650；保留已有成果及原三处失败复现。没有新目标、分支、发布或部署。

本块通过可选 Harness provider 复用原 Tenant/TenantMembership、PlatformThreadBindingRecord、CustomAgent、SkillReference 及 Paths。原 read_file/ls/write_file/str_replace/view_image/present_files 和 Gateway 产物下载/归档/PPTX 预览、上传列表、线程删除、LangGraph 历史/结果/流均接当前身份；没有新资源或线程登记表。宿主文件目录从原 Paths 的租户/成员/线程推导，运行状态仅校验一致性，不作为目录授权。

- 文件与图像内容采用逐级 O_NOFOLLOW 的持有描述符，限制普通单链接文件，读取前后核验文件及祖先身份。目录列表保留两层浏览，排除别名。写入/替换同样在持有描述符上操作，不能编辑 Skill 原文。写入中权限变化或结果未知时不宣称未写入，需检查输出。
- 当前 Native Skill 图像读取使用原具体选择/资源实例/字节快照；与文本共享撤权、禁用、替换检查，独立嵌套 SKILL.md 亦是授权边界，不从选中父目录继承读取。
- 产物展示仅允许当前拥有且真实可读的 outputs 文件。下载和归档处理已核验字节快照，避免 FileResponse 延迟重开原路径。PPTX 转换处理临时私有副本；缓存按内容摘要区分并仍先执行权限检查。浏览器响应禁止缓存撤权后的旧内容。
- 当前成员与租户状态在读取前后检查；历史长流在每一内容块发送前检查原线程归属。撤权后不再返回新的内容。已经合法发送、由用户保存的内容不具有远程撤回语义。
- 自动来源诊断在再次核对当前来源授权后写入原线程绑定，并在原 LangGraph 元数据标记当前授权管理员为 owner；图像/文件保护不依赖未认领的自动线程。此接入测试验证 SDK 契约与真实数据库事实，不计为真实模型调用。
- 线程旧数据仅凭原 LangGraph owner_user_id/owner_tenant_id 元数据证明后认领，不能凭磁盘目录或调用者字段认领。跨成员/租户请求不能删除全局 thread_id 检查点。

## 明确保留的边界

本块证明当前线程拥有者访问已有线程文件/结果，不证明旧/default/terminal 的全局命令或全部 Sandbox 工具已作用域化，也不证明远端挂载、GUI、外部模型或工具验收。独立 Harness 没有宿主数据库；其图像限制线程目录，但没有租户数据库撤权能力。宿主没有 provider 时带 tenant/Native 身份拒绝回落。

原线程绑定目前以名称保存 Agent 选择，尚无 N08 版本/资源来源快照。本块没有引入 N08 持久执行或新产物来源事实；不能据此声称旧结果的派生资源来源 ACL、版本替换、复制分享/目标重授权已经完整闭环。自动诊断事件专用结果/SSE、当前来源条件与实际取消/unknown 是第一里程碑紧接的运行功能项。仍按原事件/Policy/Approval/Action/Audit 推进，不能将其排除出最终范围。

PPTX 预览原路径保留；独立 Office 完整性仍待，当前转换契约测试不代表真实 Office/外部模型调用。文件下载现在返回核验快照；单范围、多范围、后缀范围及非法范围复用原 Starlette 解析与 multipart 格式，增量独立验证；超大文件的流式内存控制仍需明确验收，不能以普通小文件下载测试裁定已完成。

N04 真实数据库/模型/外部 Tool/可计数工单接收端的配置引用仍缺失；本批自有 PostgreSQL 和 OS/容器证据不能替代。N07 远端 CI 尚无真实结果。M1 未退出；N08 不启动，全部 N01–N15、O01–O42/F01–F12 和原退出门继续保留。
