# 外部 SDK 隔离构建与本地 MCP 兼容

2026-10-16（Asia/Shanghai）。沿用 `codex/octop-integration` 和 `915ba0b`。

## 新增可用能力

外部三个原始 MIT wheel（Browser/Gateway/Memory 1.0.0）和已过滤的 Harness 1.0.1 源码可以生成独立、可重复构建的兼容 worker。准备脚本先核对来源、许可、归档和成员哈希，生成收据；三个 wheel 保留原字节，Harness 仅保留已有过滤源码和 LICENSE。51个外部受限成员、186个主仓 Office 成员保持排除。

Worker 使用独立、带哈希的 wheel-only 依赖锁和固定基础镜像 digest。上游唯一版本约束与核心依赖必须满足；以后新增要求或上游锁版本不匹配时明确失败，不能静默复用旧 worker 锁。宿主 uv.lock、LangGraph/DeerFlow 和原权限/Policy/Approval/Action/Audit 未替换。

实际 worker 适配器0.3.0/MCP1.28.1/Deep Agents0.7.9，宿主保留适配器0.2.1/MCP1.29.0。真正存在的冲突是适配器最低版本；不能误写成 MCP 库版本冲突。Harness 是 source-only，实际 `__version__=0.0.0+unknown`、没有安装分发元数据；收据单独记录源版本1.0.1，未伪造官方分发。

[运行说明](../../../../docker/octop-worker-compat/README.md)提供准备→构建→固定镜像ID探针的实际命令，当前CI加入同样入口，远端运行仍待授权和实际执行。

## 未完成边界

这是兼容沙箱，不是原生业务 worker 注册。计数只属于本地合成echo；不计N04真实工单次数。Browser真实控制、Gateway各通道、Memory可选后端、Harness实际模型/工具、原资源身份/审批/审计接入、取消/恢复和完整外部Runtime仍待逐项实施验收。当前协议仅本地版本化探针，不是完整业务执行协议。

b5→b6→b5验证固定宿主接缝和原来源升级回退，不代表任意旧版worker镜像可直接替换运行。本块没有先前生产worker可回退，宿主继续用原SDK；删去兼容入口不会改变原业务运行。

完整N01–N15、O01–O42/F01–F12及PrismOS M1–M7/Golden/五门保持。M1仍待N04真实模型→原受控工具→可计数工单、真实远端命令/挂载/终止和全部工具、N07远端CI等；N08持久执行/委派不启动。完整Office高级能力、专家/子Agent和外部业务接入继续保留。未推送、发布、部署。
