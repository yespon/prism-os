# 当前命令功能块的范围与继续退出条件

本批接入原Native确认资源到bash真实执行：本地bubblewrap命名空间、原AIO配置镜像的临时Docker命令实例，读取当前授权资源、Python/JavaScript/脚本与线程虚拟环境、保留当前线程产物；当前资源/Agent撤回停止包括脱离进程组的子进程，未确认输出丢弃，容器create成功但回复丢失可检查本次标签归属再清理。SQLite、独立PostgreSQL、真实命令与自有容器验证的范围必须与相应日志一致。

这不是整个“运行与资源闭环”退出。远端Provisioner的原接口忽略挂载参数，当前Native已确认选择不会退回全局实例；其功能仍需原远端接口与实际环境支持。Apple Container、目标Docker/Kubernetes卷UID/GID和命名空间能力仍待验；当前缓存镜像用于有界实际命令，不证明默认完整AIO镜像/GUI/设备/交互服务功能等价。

旧/default/terminal、全部图像/文件/结果/历史访问、自动来源与事件条件的受保护运行中核对、当前目的限定Secret/网络/所有Tool的PEP、复制分享与目标重授权仍属下一完整功能块。网络保留原语义，不能仅凭文件系统隔离证明外发权限；现有显式模型环境接口不等于通用Secret目的限制已完成。未知产物或外部副作用不猜测回滚/成功，不重发；没有新业务Run事实。
