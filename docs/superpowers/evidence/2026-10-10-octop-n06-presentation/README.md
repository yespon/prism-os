## 功能与来源

- 固定 b6 归档新增原样提取 28 题的路由源文件（`.py.txt` 静态数据）和 52 个 SVG；累计迁入 902 个文件，保留源码视图/原始成员收据仍分别为 3,585/3,771。237 个被排除资源继续仅保留收据和独立实现目标。
- 宿主静态读取问卷字面量，计分对照固定源码；保留最低 20 题、首极平票和百分比公式，前端完成 28 题后显式应用到草稿。API 不保存答案或自动写 Agent。
- 现有 JSON 元数据保存基础提示、人格/语言、欢迎语、有限头像 ID 与快捷提问；API 只返回有界字段。更换/清除人格、重复保存和旧客户端有效提示往返不叠加。旧记录摘要不符时保留其提示内容。
- 欢迎语和快捷提问本地化复制、可编辑并持久化；点击快捷提问只填入聊天输入框。原样来源目录通过 `.gitattributes` 保留 CRLF/空白，宿主文件仍用正常文本规则；头像经来源与 XML 检查，以认证客户端取得，切换/关闭时取消请求并释放 Blob URL。
- 草稿按语言、租户和 Agent 名称重置；旧目录/预览/计分/头像、名称预检及保存回调不污染新上下文。显示配套资源归档但未安装/授权、Office 能力待独立实现状态。

增量设计：[N06 Spec](../../specs/2026-10-10-octop-n06-presentation.md)。[validation.json](validation.json) 记录实际命令、结果、日志/代码/制品摘要及限制；日志在 [logs](logs/)。
