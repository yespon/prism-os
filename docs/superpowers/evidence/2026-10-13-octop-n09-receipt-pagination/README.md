# N09-C1 分页与收据保留接续证据

基线 `520bb13`，分支 `codex/octop-integration`。默认 100 条的原列表改为可继续分页；固定标识排序、当前身份/作用域/页大小游标及明确刷新语义，恢复改写时间不再造成旧记录漏读。坏记录独立显示，DB 故障不能成为“坏收据”；前端可追加、重查并核对第一页以外的操作结果。

保留规则为全部收据保留、不自动删除，显式维护仅原自有暂存 abort。已发布/未知/冲突/登记/禁用文件和无法证明归属的内容不按年龄清理、不猜测回滚。备份复制后的目录身份改变仍须原恢复/资源维护门核对，不能自动认领。

[Spec](../../specs/2026-10-13-octop-n09-receipt-pagination.md) 定义协议、并发刷新、故障和保留边界；[validation.json](validation.json) 固定实际最终门禁与未退出范围；[candidate.json](candidate.json) 固定独立检出输入；[receipts.json](receipts.json) 核对证据字节。
