# 原 Sandbox 授权资源命令执行增量

继承原 N09/C2、宿主运行时与资源/执行治理；无新 schema、注册表、持久 AgentVersion 或 Task/Run/Attempt 事实。基线 `8ba73a6`，原普通/legacy路径保留；已确认 Native 选择不能复用挂有全 Skill 根的执行实例。

## 可运行功能

原 bash 在初始化共享 Sandbox 之前请求宿主命令钩子。原 Native 身份、当前成员/租户/启停和原具体资源在原引用事务里核对；线程目录由原 Paths 与可信 tenant/actor/thread 派生，状态中任意路径不能变成挂载。读取当前完整成员快照，经持有描述符验证身份/摘要与前后树一致，再复制到原数据根的私有临时视图。只读视图包括授权来源，已登记嵌套来源及有独立主文件的未登记嵌套内容须自身授权；不复制原 UserConfig、服务环境、宿主私有目录。脚本执行位保留。

本地 Provider 使用现有 bubblewrap 的用户/挂载/PID命名空间，仅暴露系统运行资源、配置 Python/Node/npm、授权视图与三个当前线程目录，源只读；子进程从显式安全环境启动，不继承宿主环境。网络保持原命令路径语义，不能据此声称网络/Secret/全部Action治理已退出。[bubblewrap 官方职责与限制](https://github.com/containers/bubblewrap#sandbox-security)说明隔离强度取决于调用策略，本实现不把工具名称本身当安全保证。

AIO本地容器 Provider 使用原配置镜像创建每条命令的独立临时实例，复用原宿主数据根映射；不采用原全局 Skill 挂载、配置任意mount/环境，也不预先获取原全局实例。只挂载本次视图与线程目录，源及镜像根只读、drop all capabilities、no-new-privileges，镜像进程以应用UID/GID使用已有数据目录。只有缓存/配置镜像可用时运行，不隐式拉取替代镜像。保留 Python/JavaScript、选中脚本、线程虚拟环境和产物；GUI/设备/长期交互能力仍走原接缝逐项验收，不算本批完成。

执行前、期间和返回前重新核对当前权限、配置和资源。失效停止本地PID命名空间或自有容器，丢弃未确认结果；线程产物和任何外部副作用不猜测回滚。容器create响应丢失时仅匹配本次随机lease标签后检查/清理，无法确认保留unknown检查要求，不误删其他容器。没有把瞬时lease当业务Run；原Policy/Approval/Action/Audit及未知不重发语义保持。

## 未退出条件

远端Provisioner的原创建请求未传授权挂载，Native确认选择明确不允许退回全局执行；需补远端挂载/镜像/UID、取消/回收与目标环境证明。Apple Container及Linux缺命名空间/无bubblewrap的部署保持明确待支持/待验证，不能把拒绝算可用。目标Docker/Kubernetes卷的UID/GID、配置与实际支持范围需N04/N07验收。

旧名称/default/terminal、所有文件/图像/结果/历史ACL、自动来源/事件条件在Tool运行中的受保护复核、整个网络与目的限定Secret/PEP、真实模型和外部Tool/工单次数、复制分享目标重授权及完整C2仍未退出。本地命令/临时容器实测不替代真实模型/外部服务。

## 按功能块验证

改变的后端执行输入须当前完整后端和相关拒绝/恢复/取消/unknown回归；数据库只重验本批涉及的引用/当前权限行为，原迁移/安装恢复的未变输入保留历史范围。同一命令块的中间失败先修复再重验对应用例，不逐次开启全栈验收。必要静态/品牌/来源、制品输入/历史构建追踪核对及固定宿主升级回退保留；未改前端不重编译，不将历史构建改称新运行。
