# N06：专家内容配置与人格体验增量设计

状态：本地实施和验证完成，证据见 [N06 README](../evidence/2026-10-10-octop-n06-presentation/README.md)；N04 真实环境待配置引用，M1 未退出，本切片不实施 N08。

用户路径为模板筛选与预览 → 人格选择或 28 题测验 → 欢迎语/头像、快捷提问和基础提示编辑 → 既有 CustomAgent 保存 → 重新打开及聊天欢迎展示。沿用现有所有者、租户管理员及共享权限；测验与头像目录需认证和租户上下文，测验不直接写 Agent。

固定 b6 归档中原样提取问卷路由源码为 `.py.txt` 数据，宿主仅静态读取 `_QUESTIONS` 的字面量，不导入 Octop 路由或身份/存储栈；52 个原样 SVG 纳入同一来源摘要。问卷每个维度 7 题，共 28 题；保留上游 20 题最低计分、首极平票和 50–85% 展示公式，API 对非法题号/答案明确拒绝。前端完成全卷后可显式应用结果到草稿，不保存问卷答案。

使用现有 Agent JSON 元数据保存基础提示、人格/语言及欢迎语、有限目录头像 ID。响应只投影有界展示字段及基础提示，绝不返回任意元数据。有效提示 = 基础提示 + 一次人格行为提示；更换/清除人格、重复保存及旧客户端有效提示往返不能叠加。旧记录仅在有效提示摘要和已知人格后缀相符时拆分，摘要不符保留原提示。编辑不替换模板来源快照。模板仍不安装或授予配套资源，受限 Office 对应能力继续明确标记待独立实现。

头像只能取固定目录 ID，经来源摘要与 XML 元素/属性检查后，以认证 SVG 图像返回；无外部地址、脚本、事件或嵌入 HTML。浏览器使用认证客户端取得 Blob 并清理对象 URL。欢迎语按纯文本呈现，限制 2,000 字符。快捷提问按模板语言复制并可编辑，最多 32 项，标题/描述/正文分别限制 100/300/4,000 字符；点击只填入聊天草稿，须用户另行提交，不自动调用工具或启动任务。

草稿在关闭、租户、语言和 Agent 名称变化时重置；异步目录、预览、问卷与头像请求取消或忽略失效结果，快速模板选择仅最后一次可应用。名称预检忽略旧请求结果，保存后的回调核对当前草稿及实时租户。租户与语言变化不重新写入旧 Agent，也不保留旧租户草稿。

验收涵盖真实数据库的创建/读取/编辑/清除/重新读取、跨租户及共享权限、旧记录兼容、16 种测验结果和错误输入、全部头像来源与认证；前端须验证草稿保存及重新打开、问卷显式应用、语言/租户/关闭/快速选择的延迟响应与错误重试。构建、完整回归和升级回退随后形成独立证据，来源导入 902 不等于全部 Octop 运行能力完成。
