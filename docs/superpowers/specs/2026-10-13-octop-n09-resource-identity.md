## 已重现的问题与修复

实际 SQLite/文件与 HTTP 重现：同名 public、shared、personal 在可见列表中被合并；scope 查询被忽略，个人详情误选 public；public 详情实际读共享目录；个人登记被指向另一用户目录时详情读取该文件。真实 QueryClient 重现跨租户/用户共享查询缓存。

资源列表保留三种具体来源。public 标识由已发现的相对来源路径摘要产生，登记资源由原生 id、当前 tenant/user/name 及 UTC 创建时间生成标识；已有创建字段提供代际边界，不添加新列。单靠 SQLite 可复用的整数 id 不足以证明资源实例；删除/重建后旧标识不得重新绑定。标识是选择器，不能提供权限或内容版本证明。

详情可携带 scope/resource_id，先从当前身份可见的原登记/来源选择具体项，然后按服务器 actor/tenant 的目录边界读取。显式标识撤回/不存在/错作用域/他用户/他租户返回不存在，不按同名 public 回退。未携带选择器的原名称 URL 保留原 public 默认；实际 public 目录正确读取。

个人/共享元数据读取对应目录，不从同名来源借用描述或许可。安装目录、相对目录或别名与当前拥有者目录不符时不读取，登记和文件保持；missing/location_unverified/metadata_unverified 记录继续可见。files_status=verified 只说明可见来源的主 SKILL 元数据/位置检查，不证明全部配套文件摘要、依赖、工具绑定或执行授权；复制前须另行读取及核对完整来源。

真实 category=public 的租户记录继续作为原 public 启用覆盖。custom shared 同名项属于不同资源，不再充当公共开关；原运行时未限定的名称继续 public 默认。禁用或无法核对主文件时不返回 use 提示；共享管理提示只来自当前租户管理员，平台角色单独不获得原共享写入权限。当前提示不能替代服务端重新授权。

## 当前身份与界面

skills/availableSkills/tenantSkills 缓存及 Agent 编辑器的技能查询绑定当前 tenant、用户、会话和角色；缓存 session 必须匹配实时 token。身份不就绪时隐藏旧数据、不读取；请求携带 AbortSignal，前后复核实时身份，晚响应不能进入新身份缓存。

列表使用具体标识作 React key 和详情导航参数，scope/name 作为旧响应兼容回退。详情按身份及来源重新挂载，清除旧表单与测试会话；旧读取取消/晚响应废弃。已发出的旧保存/生成不代表服务器回滚，旧 UI 响应不得在新来源导航或提示成功。
