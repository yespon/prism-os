# N09-C1 界面接续：安装确认、结果核对与恢复

基线 `70853b8`，分支 `codex/octop-integration`。本次接续原 TenantSkill 安装服务；原 PrismOS 身份、租户、资源权限及执行治理门保持。完整 C1 与 N09 不因该界面交付而退出。

## 用户操作与权限

专家配套资源预检中的 ready Skill 可进入安装确认，默认当前个人范围；只有已核对的当前租户 `tenant_admin` 可选择共享。平台角色或另一租户缓存角色不授予共享安装权。服务端继续决定 actor/tenant 及路径，前端请求仅携带 scope、已检查的来源包摘要；成功后重新读取安装事实。登记不能代表 Agent 绑定、依赖通过或获得执行权限。

个人技能中心及租户技能管理提供按需检查导入记录；恢复和放弃自有暂存各有独立确认。只有完整暂存或已核对发布文件的待登记记录提供恢复；已登记及禁用记录不提供恢复/启用操作。放弃只可指向未登记、未发布的自有暂存；后端归属核对仍为最终判据。

请求结果不确定或冲突时清除旧的可操作记录，用户必须再次检查后才能继续。网络错误、服务端未知及携带 operation_id 的失败提示先核对；401/403 与没有 operation_id 的 409 提示实际拒绝/冲突。线程安装的原 string message 契约保留，附加可选 operation_id。

## 会话及生命周期

操作身份由当前租户、会话用户及会话 ID 组成，缓存 session token 必须与实时 token 一致，渲染 key 不含 token。操作前再检查实时身份；租户、会话、资源摘要、语言或关闭界面变化使旧确认和响应失效。新界面 abort 请求并丢弃晚响应，不能据此声称服务器回滚。原上传入口也在关闭及身份变化后丢弃旧成功提示和关窗操作，避免影响重新打开的界面。

后端记录返回 phase（操作收据历史阶段）与 state（当前文件/原生登记核对结果）两个字段。观察到已有登记不改写成操作创建登记；禁用保持。没有新 schema、迁移、Skill 注册表或执行事实。

## 收据边界与下一项

现有记录保存、不自动 GC；放弃只清理已证明归属的暂存，不删除已发布文件。当前列表仍按修改时间返回最近 100 项。该限制不能作为最终保留/查询策略；本批不宣布完整 C1 退出。

下一有界批次必须增加可核对、稳定的分页，证明超过 100 条、状态更新及并发新增时仍可定位待恢复操作；明确未完成/未知/冲突收据及已登记/放弃收据的保留和显式维护规则。不得按超时猜测 DB 失败或删除未知目录。验收后再推进 C2 共享/复制/撤回，C3 非 Skill 显式绑定，C4 真实工具/依赖与执行治理，C5 专家行为和独立 Office。

N07-B 远端 CI、N04 真实目标环境保留 P0。当前尚缺可定位的目标 DB、模型与工单接收端配置引用，M1 未退出，N08 不实施持久执行。

## 构建资源接续

实际默认 Turbopack 构建与并行检查导致 8 GiB 主机内存持续换页，记录并终止本轮自有进程后恢复。生产构建入口默认选择本地 Next CLI 支持的 Webpack；可显式传编译器参数。路由 typegen 和严格 tsc 仍在编译前顺序运行，私有检查完成标志保持；真实错误路由须在编译前被拒绝。最终统一构建、独立检出按单 CPU/Node 1 GiB 堆上限顺序验证，不改变应用路由或执行治理。
